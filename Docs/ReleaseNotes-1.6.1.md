# PHP Switcher 1.6.1

- Add a downloadable DMG with the application, an Applications folder shortcut, and installation instructions.
- Generate and verify the DMG automatically when preparing a release.
- Verify that the DMG contains exactly the same application as the signed update ZIP.

## Installation

Download [PHP-Switcher-1.6.1-arm64.dmg](https://github.com/danny3b/php-switcher/releases/download/v1.6.1/PHP-Switcher-1.6.1-arm64.dmg), open it, and drag **PHP Switcher.app** onto **Applications**. Eject the image and launch the application from Applications.

Existing version 1.6.0 users can instead open **Settings → App updates → Check for updates**, then choose **Install and restart** after the download finishes.

Requires macOS 14 or later on Apple Silicon. This build is ad hoc signed and is not Apple-notarized.
