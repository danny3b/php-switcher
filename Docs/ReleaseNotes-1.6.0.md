# PHP Switcher 1.6.0

- Check for application updates at startup and every six hours.
- Check manually from Settings or the application/menu bar menus.
- Download new versions automatically, with separate preferences for checking and downloading.
- Install downloaded updates with **Install and restart**, preserving application settings and PHP installations.
- Block update restarts during PHP operations or while a configuration editor is open.
- Verify signed GitHub update feeds and archives using Sparkle.
- Provide update controls and status messages in Polish and English.

This is the first release with an integrated updater. Install it manually once when upgrading from version 1.5.0 or earlier. Subsequent signed releases can be installed from within the application.

Requires macOS 14 or later on Apple Silicon. This build is ad hoc signed and is not Apple-notarized.
