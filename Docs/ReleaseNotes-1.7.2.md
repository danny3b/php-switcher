# DevŻbik 1.7.2

PHP Switcher is now **DevŻbik**. This release updates the application name in the window, menus, settings, translations, and release packages.

- Existing PHP installations, preferences, configuration backups, and the update channel continue to use their original identifiers and locations.
- The application bundle and download filenames use the ASCII spelling `DevZbik`.
- This release changes the name; MySQL database import is not included yet.

## Update

In PHP Switcher, open **Settings → App updates** and click **Check for updates**. Download version **1.7.2**, then choose **Install and restart** when it is ready.

For a new installation, download [DevZbik-1.7.2-arm64.dmg](https://github.com/danny3b/php-switcher/releases/download/v1.7.2/DevZbik-1.7.2-arm64.dmg), open it, and drag **DevZbik.app** onto **Applications**.
