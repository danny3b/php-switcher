# PHP Switcher 1.7.0

- Ask for the application language on first launch when no valid choice has been saved.
- Suggest a supported macOS language and save the choice only after confirmation.
- Add German, French, and Italian alongside Polish and English, including PHP installation, configuration, security, and application update messages.
- Preserve existing language preferences and allow changing the language in Settings at any time.

## Installation

Download [PHP-Switcher-1.7.0-arm64.dmg](https://github.com/danny3b/php-switcher/releases/download/v1.7.0/PHP-Switcher-1.7.0-arm64.dmg), open it, and drag **PHP Switcher.app** onto **Applications**. Eject the image and launch the application from Applications.

Existing version 1.6.0 or later users can open **Settings → App updates → Check for updates**, then choose **Install and restart** after the download finishes.

Requires macOS 14 or later on Apple Silicon. This build is ad hoc signed and is not Apple-notarized.
